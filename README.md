## The word

> arnesa

One word, one username: the entrant's own make.fun handle, sent exactly as it is worn — no spaces, no padding, no gloss.

## How to run

Run `node main.ts` from the repository root. The program creates `/output` if needed and writes the handle exactly, with no trailing newline, to `/output/entry.txt`.
